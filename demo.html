TikTok Login Kit demo for app review

Matzscho TikTok Composio Connector

This page demonstrates the intended end-to-end TikTok integration flow for a private web connector. The app uses TikTok Login Kit OAuth to authorize the owner’s TikTok account and then reads only basic profile information and profile statistics through Composio/Hermes.

Visible user flow

The user starts on this website, reviews the requested scopes, clicks the TikTok Login Kit entry point, authorizes in TikTok, and is redirected back to the verified callback URL.

♪ Continue with TikTok

For review demonstration, this button opens the verified callback page. The production OAuth authorization URL is generated by Composio/TikTok during connection.

Selected product and scopes

Product: Login Kit only

  • user.info.basic — basic TikTok user information
  • user.info.profile — profile information
  • user.info.stats — profile statistics

No Share Kit, Display API, Content Posting API, upload, publish, ads, research, or commerce scopes are used.

End-to-end integration flow

Data handling summary

The app is private and used by the owner only. It does not offer public accounts, publishing, uploads, advertising, or third-party data sharing. OAuth tokens and connection metadata are handled by Composio for the purpose of executing the authorized TikTok API calls.
